# Attacker-Defender Games

Phase 6 represents attacker-defender pairings as a restricted empirical game.

Outcomes include attack success, severity-weighted harm, task utility, oversight cost, attack cost, detection count, and prevention count. Payoff matrices support best responses, attacker regret, defender regret, exploitability, maximin defender selection, minimax attacker selection, and simple empirical mixed strategies.

The implementation does not claim a true equilibrium. It reports restricted-game quantities for the tested attacker and defender classes.
