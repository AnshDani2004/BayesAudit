# Attack Selection

Attack selection is separated from attack capability.

The same primitive set can be evaluated under every eligible opportunity, random opportunity selection, positive fixed utility, low estimated detection risk, maximum expected utility, Bayesian posterior risk, and public policy awareness.

Selection-bias analysis compares all opportunities, selected opportunities, conditional safety, unconditional safety, risk-score shift, and harm shift. Raw monitor accuracy should not be compared across attacker classes without accounting for the changed opportunity distribution.
