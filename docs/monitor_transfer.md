# Monitor Transfer

Phase 7 evaluates Phase 5 synthetic-trained monitors on real-pilot observations before any pilot-test retraining. Metrics include AUROC, AUPRC, precision, recall, Brier score, log loss, calibration slope/intercept, abstention, OOD diagnostics, and small-sample warnings.

Pilot-only recalibration is exploratory. It must not become a confirmatory method unless declared before Phase 8 and fit only on a designated calibration split.
