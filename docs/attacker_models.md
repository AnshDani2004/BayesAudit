# Attacker Models

Phase 6 implements ten attacker families behind a common stateful interface:

- honest
- indiscriminate
- random selective
- opportunistic
- risk avoiding
- expected utility
- Bayesian selective
- start-stop
- policy aware
- oracle attacker

Controlled comparisons keep primitive capability fixed and change only the selection policy. The oracle attacker is evaluation-only and blocked outside explicit evaluation mode.
