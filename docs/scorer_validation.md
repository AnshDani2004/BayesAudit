# Scorer Validation

Phase 7 compares deterministic scorer outputs against human labels on real-model traces. Each comparison records automated result, human label, agreement, disagreement type, scorer error category, recommended correction, whether historical pilot output changes, and whether the task or scorer is responsible.

Scorers are ready for Phase 8 only after deterministic behavior, false-positive modes, false-negative modes, internal-only/final-output distinctions, versioning, tests, and repair history are documented.
