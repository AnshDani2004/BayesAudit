# Phase 8 Preregistration Draft

This is a draft scaffold, not a finalized preregistration.

It will separate pilot findings from confirmatory hypotheses and record research questions, primary outcomes, secondary outcomes, model families, task sampling, architectures, oversight conditions, attacker conditions, audit budgets, exclusion rules, scorer versions, annotation plan, statistical models, multiple-comparison policy, sensitivity analyses, stopping rules, cost ceiling, deviations from the original project plan, and pilot-informed assumptions.

Current status:

- No real-provider pilot results have been generated.
- No provider or exact model identifier has been explicitly supplied for empirical execution.
- Pilot-informed assumptions are therefore limited to mock-safe infrastructure validation and dry-run cost plans.
- Confirmatory hypotheses must not be finalized from the current Phase 7 state.

Required before finalizing this draft:

- Stage A provider connectivity result with cache/resume verification.
- Stage B workflow-functionality review.
- Stage C measurement-validation pilot with privacy, authorization, and evidence tasks.
- Human annotation sample and scorer-human disagreement categories.
- Monitor-transfer, calibration-transfer, OOD, and oversight-feasibility summaries from real traces.
- Updated Phase 8 cost and sample-size assumptions from actual token, request, and failure rates.

Phase 8 must not begin automatically.
