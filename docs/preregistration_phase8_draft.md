# Phase 8 Preregistration Draft

This is a draft scaffold, not a finalized preregistration.

It will separate pilot findings from confirmatory hypotheses and record research questions, primary outcomes, secondary outcomes, model families, task sampling, architectures, oversight conditions, attacker conditions, audit budgets, exclusion rules, scorer versions, annotation plan, statistical models, multiple-comparison policy, sensitivity analyses, stopping rules, cost ceiling, deviations from the original project plan, and pilot-informed assumptions.

Phase 8 must not begin automatically.
